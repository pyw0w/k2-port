# K2 (Port) — Advanced Tank

A standalone Factorio 2.1 mod that adds the Advanced Tank from Krastorio2, with Space Age compatibility.

## Features

- Advanced Tank entity with 5 weapon slots (machine gun, laser cannon, 3 railgun cannons)
- Custom ammo items: Railgun Shell, Explosive Railgun Shell, Antimatter Railgun Shell, Impulse Rifle Ammo
- Custom projectiles and explosion effects
- Custom damage type (k2-explosion)
- Tech scaling bonuses for railgun and impulse rifle ammo categories
- Equipment grid, custom fuel category
- Space Age compatibility (upgraded recipes with tungsten, quantum-processor, superconductor)
